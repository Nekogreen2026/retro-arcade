# RETRO ARCADE

ブラウザで遊べるレトロゲームセンター。夜の店内に並んだドット絵の筐体から、遊びたいゲームを選んで入る。

- ビルド不要。素のHTML/CSS/JavaScriptだけで動く
- 画面は256×240ドット。スマホの縦持ち・横持ち・PCのどれでも、ドットをぼかさず整数倍で中央に表示する
- GitHub Pages にそのまま置けば公開できる（リポジトリの Settings → Pages で、公開元にこのブランチのルート `/` を選ぶ）

## 遊び方

### トップページ（店内）

| 操作 | スマホ | PC |
| --- | --- | --- |
| ゲームを選ぶ | 筐体をタップするとそのまま入る | 筐体をクリック／`←` `→` で選んで `Enter` |
| 筐体が多いとき | 左右の矢印をタップ | `←` `→` で店内が流れる |

「調整中」の貼り紙がある筐体は、まだ入荷していない台。最後に遊んだ台が次に開いたとき選ばれている。

### 居合（いあい）

負けるまで鬼を斬り続ける勝ち抜き戦。

1. 静かな夜の野原でしばらく待つ（2〜6秒）。
2. 「カンッ」という音とともに **鬼** か **猫天使** が現れる。
3. **鬼** なら、すぐに斬る。間に合えば反応時間（ミリ秒）が出て次の勝負へ。
4. **猫天使**（頭に輪がある）なら、斬らずに耐える。0.6秒耐えれば猫天使は去り、また待ちに戻る（続けて現れることもある）。

| 負け | 条件 |
| --- | --- |
| 遅い | 鬼を猶予時間のうちに斬れなかった |
| 天罰 | 猫天使を斬った |
| 早まったな | 何も現れないうちに斬った |

**操作**：タップ／クリック／スペースキー（押した瞬間に判定。押しっぱなしは1回とみなす）

**難易度**：撃破数が増えるほど厳しくなり、50体で最大になる。

| | はじめ | 最大 |
| --- | --- | --- |
| 鬼の猶予 | 1.0秒 | 0.6秒 |
| 猫天使の割合 | 3割 | 4割 |
| 待ち時間 | 3〜5秒 | 2〜6秒（揺れ幅が広がる） |

**称号**：5体「見習い」、10体「十人斬り」、30体「剣豪」、100体「百鬼斬り」。到達した瞬間と終了画面に出る。

**終了画面**：撃破数・称号・最速反応・平均反応・負けの理由・救った猫天使の数を表示。

- 「もういちど」で即再挑戦（PCは `Space` / `Enter` / `R`）
- 「結果を送る」で結果を共有。スマホは端末の共有メニュー、共有メニューのないPCはクリップボードにコピーする（PCは `S`）
- 「もどる」でトップへ（PCは `Esc`）

共有文の例：

```
居合 十二体斬り【十人斬り】／最速 231ms／救った猫天使 3匹
https://<ユーザー名>.github.io/retro-arcade/
```

**自己ベスト**：「最多撃破数」と「最速反応」を、**PCの部**と**スマホの部**（指で操作する端末）に分けて保存する。更新すると紙吹雪とファンファーレで祝う。

反応時間は「絵が画面に出たフレーム」から「タップ／キーを押した瞬間」までを測っている。

### 菌糸ライフ（きんしライフ）

鉢でキノコを育てて図鑑を埋める育成ゲーム。時間は実時間で進み、ブラウザを閉じているあいだも育つ。1日に何度か、数十秒のぞくくらいのテンポで遊ぶ。季節は現実の日付、天気は名古屋の実際の天気と連動していて、台風・猛暑・長雨・初霜の日にしか出会えないキノコもいる。

1. 空いた鉢（3つ）をタップすると胞子をまく。
2. **胞子 → 幼菌 → 成菌** と育つ。成菌になったらタップで収穫し、図鑑に「採取」として載る。
3. 収穫せずに放っておくと **しおれ**、さらに置くと **乾燥標本** になる。枯れて消えることはなく、乾燥標本は自動で図鑑に「標本」として載る（鉢をタップすると片づく）。

胞子・幼菌・しおれの鉢をタップすると、次の段階までのおおよその時間が出る。鉢の下のゲージは、緑が育ち具合、金がしおれるまでの残り、灰が乾くまでの進み。

**つまみ**：湿度・温度・光を、それぞれ3段階（低・中・高／暗・中・明）で切り替える。ケースの中の霧・水滴・霜・熱気・明るさが、いまの環境を表す。

| つまみ | 育ちの速さ | 持ち（しおれ・乾燥までの長さ） |
| --- | --- | --- |
| 湿度 | 高いほど速い | 高いほど長い |
| 温度 | 高いほど速い | 低いほど長い |
| 光 | 暗いほど少し速い | 暗いほど少し長い |

すべて「中」のとき（春のおだやかな日）、胞子→幼菌が2時間、幼菌→成菌が2時間、成菌→しおれが8時間、しおれ→乾燥標本が6時間。つまみと季節次第で、成菌までは約2〜10時間、しおれるまでは約2〜20時間と変わる。ケースの上に、いまの環境での「育ち」「持ち」が出る。

**季節**：現実の日付（日本時間）で決まる。季節ごとにケースの湿度・温度の基本がずれる（つまみ1段を1とした量）。つまみの段の下の細い白線が、季節と天気を足した「ケースの中の実際の状態」。たとえば冬は温度を「中」にしても実際は「低」になり、ケースに霜がつく。

| 季節 | 期間 | 湿度 | 温度 |
| --- | --- | --- | --- |
| 春 | 3/1〜6/5 | ±0 | ±0 |
| 梅雨 | 6/6〜7/19（名古屋の平年の梅雨入り・梅雨明けごろ） | +0.5 | +0.25 |
| 夏 | 7/20〜9/22 | +0.25 | +0.5 |
| 秋 | 9/23〜11/30 | −0.25 | ±0 |
| 冬 | 12/1〜2月末 | −0.5 | −0.5 |

**名古屋の天気**：[Open-Meteo](https://open-meteo.com/)（APIキー不要）から、名古屋（緯度35.18・経度136.91）の天気をプレイヤーのブラウザで取る。取るのは、いまの気温・湿度・降水量・風速・最大瞬間風速（m/s）と、過去3日（と今日）の日別の降水量・最低気温。タイムゾーンは Asia/Tokyo。

- 取得は1時間に1回まで（失敗も1回に数える）。結果は保存しておき、1時間たつまでは開き直しても取りに行かない。開いたままなら1時間ごとに取り直す
- 取れなかったときは、季節なりのランダムな天気（平年の気温・湿度のまわりで、時刻なりにばらつかせたもの）で代用する。代用中は表示が灰色になる
- 窓の左下の札に「名古屋 ○°C ○%」と天気の絵、右下の札に季節と天候イベントが出る
- 実際の気温・湿度が季節の平年からずれたぶん、ケースの温度・湿度も少し動く（最大でつまみ0.15段ぶん）

**天候イベント**：名古屋の天気から判定する。イベントは罰ではなく機会で、起きているあいだだけ特別な変種が出やすくなる。窓の空模様と環境音も変わる。

| イベント | 判定 | 起きているあいだ | 空と音 |
| --- | --- | --- | --- |
| 台風 | 最大瞬間風速20m/s以上、または平均風速10m/s以上で雨 | 空き鉢に胞子が飛んできて、予想外の種類が生える | 速い暗い雲、横なぐりの雨、稲光と雷、うなる風 |
| 猛暑 | 気温35°C以上 | 猛暑の変種が出やすい | 白く光る空と太陽、街の陽炎、蝉 |
| 長雨 | 3日続けて降水あり（1日1mm以上。過去3日すべて、または今日も降っていればおととい・きのう・きょう） | 長雨の変種が出やすい | 曇り空と雨、雨音と雨だれ |
| 初霜 | その日の最低気温3°C以下 | 初霜の変種が出やすい | 澄んだ空、窓の霜、鈴のような音 |

イベントのない日も、雨なら雨と雨音、春は花びら、秋は落ち葉、夏の夜は蛍が窓に見える。窓の下には名古屋の街並みと城。栽培室にいるあいだにイベントが来ると（去ると）知らせが出る。

**変種**：19種（いつもの10種、季節限定5種、天候イベントの4種）。どの変種になるかは、まいてから成菌になるまでに、どんな環境でどれだけ過ごしたかで決まる。季節限定の変種はその季節にしか出ない。条件はゲーム内では明かさない。育ち途中の絵はその時点の見立てで変わるので、それが手がかりになる。名前は収穫するか、乾燥標本になったときにわかる。

**図鑑**：右上の「図鑑」から開く。2ページあり、「前」「次」でめくる（1ページ目がいつもの変種、2ページ目が季節と天候の変種）。「採」は成菌を収穫した変種、「標」は乾燥標本になった変種。未発見の変種は影だけ（季節と天候の変種には、出る時期の手がかりが出る）。新しく載ったものには NEW が付く（新着があると「図鑑」ボタンに桃色の印が出る）。見つけた変種には「どの季節・天候で見つけたか」が記録され、下の2段（季節：春・梅雨・夏・秋・冬、天候：ふだん・雨・台風・猛暑・長雨・初霜）の色が付く。前の版の図鑑の記録（採取・標本の数）はそのまま引き継ぐ。季節・天候の記録は、この版になってから見つけたぶんから付く。

**留守のあいだ**：最後に開いていた時刻を保存しておき、次に開いたときに経過した時間ぶんをまとめて進める（つまみは閉じたときのまま）。季節と天気もその時刻のもので進める。長雨・初霜は日ごとの記録（過去3日ぶん）から、気温・湿度・台風・猛暑は取得してから3時間ぶんだけ当てはめる。10分以上空けて開くと、タイトルに「おかえり」と留守中の出来事が出る。

| 操作 | スマホ | PC |
| --- | --- | --- |
| 胞子をまく・収穫・様子を見る | 鉢をタップ | 鉢をクリック／`1` `2` `3` |
| つまみを回す | `－` `＋` をタップ | クリック |
| 選んで決める | | 矢印キーで選んで `Space` / `Enter` |
| 図鑑 | 右上の「図鑑」 | `Z` |
| 図鑑のページ | 「前」「次」 | クリック／端の升目からさらに `←` `→` |
| もどる | 左上の「もどる」 | `Esc` |

**デバッグ（確認用）**：URL の末尾に `?debug=1` を付けると（例：`games/kinshi/index.html?debug=1`）、次のボタンが出る。付けないときは出ない。

| ボタン | PC | 内容 |
| --- | --- | --- |
| 「+1時間」「+1日」 | `H` / `D` | いまのつまみ・季節・天気のまま時間を進める |
| 季節（窓の右下） | `S` | 日付どおり → 春 → 梅雨 → 夏 → 秋 → 冬 → 日付どおり の順に切り替える（固定中は赤） |
| 天候（窓の右下） | `E` | 実際の天気 → なし → 台風 → 猛暑 → 長雨 → 初霜 → 実際の天気 の順に切り替える（固定中は赤） |

季節・天候の固定は開いているあいだだけ（再読み込みで日付どおり・実際の天気に戻る）。タイトルの下には、取った天気の中身（取得元 API／RND と時刻、いまの降水量・風速・最大瞬間風速、過去3日の降水量・最低気温、今日の最低気温）が出る。保存データは普段のプレイと共通なので、試したあとはそのまま続きになる。

**保存**：`retro-arcade:kinshi:state`（鉢・つまみ・最後の時刻）、`retro-arcade:kinshi:book`（図鑑）、`retro-arcade:kinshi:weather`（最後に取った名古屋の天気と、その時刻）。

## ファイル構成

```
index.html, index.js   トップページ（店内）
games.js               筐体の一覧（1行＝1台）
shared/                全ゲーム共通の部品
  palette.js             16色パレット（色はすべてここから）
  base.css               画面の配置、スマホのジェスチャー無効化
  screen.js              256×240の画面と整数倍拡大、ゲームループ
  input.js               pointerdown／キーボード入力
  text.js                ドット文字（DotGothic16 / Press Start 2P）、漢数字
  audio.js               Web Audioの効果音合成
  ui.js                  ボタン、トップへ戻る
  store.js               localStorage（キーは retro-arcade:ゲーム名:項目）
games/iai/             居合
  index.html, game.js
  assets/oni.png, assets/neko.png
games/kinshi/          菌糸ライフ
  index.html, game.js
  weather.js             名古屋の季節と天気（Open-Meteo の取得・代用・天候イベントの判定）
  assets/<変種ID>-<段階>.png（19変種×5段階＝95枚）
CLAUDE.md              開発ルール
```

手元で動かすときは、リポジトリのフォルダで簡単なサーバーを立てて開く（例：`python3 -m http.server` → `http://localhost:8000/`）。

## ゲームの追加方法

1. `games/` の下にゲーム名のフォルダを作る（例：`games/kingyo/`。名前は英小文字・数字・`-`）。
2. その中に `index.html` を置く。居合の `games/iai/index.html` を写して、最後の `game.js` を自分のスクリプトに差し替えるのが早い。共通部品は相対パス `../../shared/...` で読む。
3. ゲームのスクリプトでは共通部品を使う。

   ```js
   const canvas = document.getElementById('screen');
   const ctx = RA.setupScreen(canvas);          // 256×240、整数倍で中央に表示
   const back = RA.backButton();                // 左上の「もどる」ボタン（押したら RA.goTop()）
   RA.bindInput(canvas, {
     press(ev) { /* ev.x, ev.y は画面座標、ev.t は押した時刻 */ },
     key(ev) { /* ev.code === 'Space' など */ },
   });
   RA.loop((ts) => {
     ctx.fillStyle = RA.P.night;                 // 色は必ずパレットから
     ctx.fillRect(0, 0, RA.W, RA.H);
     RA.text(ctx, 'はじめる', 128, 112, { color: 'cream', align: 'center' });
     back.draw(ctx, ts);
   });
   RA.Audio.tone({ f: 880, dur: 0.1 });         // 効果音は合成で
   RA.Store.set(['kingyo', 'best'], 10);        // → retro-arcade:kingyo:best
   ```

4. `games.js` に1行足す。これで店内に筐体が1台増える。

   ```js
   { id: 'kingyo', title: '金魚', desc: '金魚をすくえ。', color: 'orange', thumb: 'assets/kingyo.png' },
   ```

   | 項目 | 内容 |
   | --- | --- |
   | `id` | フォルダ名（必須） |
   | `title` | 看板の名前（必須。看板に入りきらなければ流れる） |
   | `desc` | 一言紹介（全角15文字まで） |
   | `color` | 看板の色。`shared/palette.js` の色名 |
   | `thumb` | 筐体の画面に映す絵（ゲームのフォルダからの相対パス。配列にすると順番に切り替わる） |

守るべきルールは `CLAUDE.md` にまとめてある（相対パスのみ、16色パレットのみ、入力は pointerdown で即時判定、など）。

## 居合の画像の差し替え方法

鬼と猫天使の絵は次の2枚。**同じ名前のPNGで上書きするだけ**で、ゲームにもトップページの筐体の画面にも反映される。コードを触る必要はない。

| ファイル | 中身 |
| --- | --- |
| `games/iai/assets/oni.png` | 鬼 |
| `games/iai/assets/neko.png` | 猫天使 |

- 推奨は **32×32ドットの背景透過PNG**。ゲームでは96×96ドットの枠に、収まる最大の整数倍（32×32なら3倍）で、枠の下端中央にそろえて描く。大きさの違う絵でも枠に収まる
- 鬼と猫天使は同じ大きさ・同じ位置に出る。見分けるヒントは絵の違いだけなので、そこが勝負の肝になる
- 色は `shared/palette.js` の16色に合わせると、サイト全体の色調がそろう
- ブラウザに古い絵が残っているときは再読み込みする（GitHub Pages は数分ほどキャッシュすることがある）

## 菌糸ライフの画像の差し替え方法

キノコの絵は仮のもの。`games/kinshi/assets/` に、**変種ごと・成長段階ごとに1枚ずつ**（19変種×5段階＝95枚）の32×32透過PNGを置いている。**同じ名前のPNGで上書きするだけ**で、ゲームにもトップページの筐体の画面にも反映される。コードを触る必要はない。

ファイル名は `変種の英字ID-段階.png`（例：`drop-adult.png`）。

| 段階 | 中身 |
| --- | --- |
| `spore` | 胞子（まいた直後） |
| `young` | 幼菌 |
| `adult` | 成菌（収穫できる姿。図鑑の絵にも使い、未発見の影もこの絵の形から作る） |
| `wilted` | しおれ |
| `dried` | 乾燥標本 |

| No. | 英字ID | 名前 |
| --- | --- | --- |
| 1 | `plain` | ヘイボンダケ |
| 2 | `drop` | シズクダケ |
| 3 | `snow` | ワタユキダケ |
| 4 | `sleepy` | ネボスケダケ |
| 5 | `lamp` | アンドンダケ |
| 6 | `ember` | オキビダケ |
| 7 | `moss` | コケモリダケ |
| 8 | `sun` | ヒダマリダケ |
| 9 | `twotone` | フタオモテダケ |
| 10 | `blink` | マタタキダケ |
| 11 | `haze` | ハルガスミダケ（春） |
| 12 | `shelter` | アマヤドリダケ（梅雨） |
| 13 | `squall` | ユウダチダケ（夏） |
| 14 | `crisp` | アキバレダケ（秋） |
| 15 | `cozy` | コタツダケ（冬） |
| 16 | `gale` | ノワキダケ（台風） |
| 17 | `shimmer` | カゲロウダケ（猛暑） |
| 18 | `gaze` | ナガメダケ（長雨） |
| 19 | `frost` | ハツシモダケ（初霜） |

- 推奨は **32×32ドットの背景透過PNG**。栽培ケースでは64×64ドットの枠に、収まる最大の整数倍（32×32なら2倍）で、枠の下端中央にそろえて描く。絵のいちばん下の行が菌床の上面に重なるので、足もとの輪郭線を最下行に置くと菌床に乗って見える
- 図鑑では32×32、タイトルでは96×96の枠に同じ決まりで描く。大きさの違う絵でも枠に収まる
- 半透明の点は使わない（パレット外の中間色になる）。色は `shared/palette.js` の16色に合わせると、サイト全体の色調がそろう
- 胞子・幼菌の絵は「その時点の環境だと何になりそうか」の見立てで切り替わる。変種ごとに色や形を少し変えておくと、それが遊ぶ人への手がかりになる

<summary>ネタバレ：変種の出現条件</summary>

まいてから成菌になるまで（胞子と幼菌のあいだ）に、ケースの中の実際の状態（つまみ＋季節＋天気）がどの段階にどれだけの時間いたかで決まる。上から順に判定し、最初に当てはまったものになる。

| 判定順 | 変種 | 条件 |
| --- | --- | --- |
| 1 | 台風で飛んできた胞子 | 何になるかは飛んできたときに決まっている（下の表） |
| 2 | カゲロウダケ・ナガメダケ・ハツシモダケ | 猛暑・長雨・初霜の中で育った割合 × 60%（その変種を見つけたあとは × 25%）の確率。くじは鉢ごとに決まっている |
| 3 | フタオモテダケ | 温度「低」と「高」に、それぞれ育つ時間の25%以上いた（寒暖差） |
| 4 | マタタキダケ | 光「暗」と「明」に、それぞれ25%以上いた（明暗の行き来） |
| 5 | ハルガスミダケ | 春・湿度 中・温度 中・光 明 |
| 6 | アマヤドリダケ | 梅雨・湿度 高・光 暗 |
| 7 | ユウダチダケ | 夏・湿度 高・温度 高 |
| 8 | アキバレダケ | 秋・湿度 低・温度 低・光 中 |
| 9 | コタツダケ | 冬・湿度 低・温度 高・光 暗 |
| 10 | シズクダケ | 湿度 高・温度 低（光は明以外） |
| 11 | ワタユキダケ | 温度 低・光 明 |
| 12 | ネボスケダケ | 温度 低・光 暗 |
| 13 | アンドンダケ | 温度 高・光 暗 |
| 14 | オキビダケ | 温度 高・湿度 低 |
| 15 | コケモリダケ | 湿度 高・温度 中 |
| 16 | ヒダマリダケ | 光 明 |
| 17 | ヘイボンダケ | 上のどれでもない（すべて「中」など） |

5〜17の「低・中・高」は、育つあいだの時間で平均した値（低＝0・中＝1・高＝2）が 2/3 未満なら低、4/3 を超えれば高、それ以外は中とみなす。季節限定（5〜9）は成菌になったときの季節で見る。ケースの実際の状態は段階のあいだの値もとり（冬の温度「中」なら0.5）、その時間は両どなりの段階に割り振って数える（0.5なら低と中に半分ずつ）。

**台風の胞子**：台風のあいだ、空き鉢1つにつき1時間に平均0.7回の割合で胞子が飛んでくる。何が生えるかは重み付きのくじで、ノワキダケ（重み5）、いつもの変種（ヘイボンダケを除く9種）とその季節の季節限定（重み1）。まだ見つけていない変種は重みが2倍になる。ほかの季節の季節限定と、猛暑・長雨・初霜の変種は飛んでこない。
