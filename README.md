# RETRO ARCADE

ブラウザで遊べるレトロゲームセンター。夜の店内に並んだドット絵の筐体から、遊びたいゲームを選んで入る。

- ビルド不要。素のHTML/CSS/JavaScriptだけで動く
- 画面は256×240ドット。スマホの縦持ち・横持ち・PCのどれでも、ドットをぼかさず整数倍で中央に表示する
- GitHub Pages にそのまま置けば公開できる（リポジトリの Settings → Pages で、公開元にこのブランチのルート `/` を選ぶ）

## 遊び方

### トップページ（店内）

| 操作 | スマホ | PC |
| --- | --- | --- |
| ゲームを選ぶ | 筐体をタップするとそのまま入る | 筐体をクリック／`←` `→` で選んで `Enter` |
| 筐体が多いとき | 左右の矢印をタップ | `←` `→` で店内が流れる |

「調整中」の貼り紙がある筐体は、まだ入荷していない台。最後に遊んだ台が次に開いたとき選ばれている。

### 居合（いあい）

負けるまで鬼を斬り続ける勝ち抜き戦。

1. 静かな夜の野原でしばらく待つ（2〜6秒）。
2. 「カンッ」という音とともに **鬼** か **猫天使** が現れる。
3. **鬼** なら、すぐに斬る。間に合えば反応時間（ミリ秒）が出て次の勝負へ。
4. **猫天使**（頭に輪がある）なら、斬らずに耐える。0.6秒耐えれば猫天使は去り、また待ちに戻る（続けて現れることもある）。

| 負け | 条件 |
| --- | --- |
| 遅い | 鬼を猶予時間のうちに斬れなかった |
| 天罰 | 猫天使を斬った |
| 早まったな | 何も現れないうちに斬った |

**操作**：タップ／クリック／スペースキー（押した瞬間に判定。押しっぱなしは1回とみなす）

**難易度**：撃破数が増えるほど厳しくなり、50体で最大になる。

| | はじめ | 最大 |
| --- | --- | --- |
| 鬼の猶予 | 1.0秒 | 0.6秒 |
| 猫天使の割合 | 3割 | 4割 |
| 待ち時間 | 3〜5秒 | 2〜6秒（揺れ幅が広がる） |

**称号**：5体「見習い」、10体「十人斬り」、30体「剣豪」、100体「百鬼斬り」。到達した瞬間と終了画面に出る。

**終了画面**：撃破数・称号・最速反応・平均反応・負けの理由・救った猫天使の数を表示。

- 「もういちど」で即再挑戦（PCは `Space` / `Enter` / `R`）
- 「結果を送る」で結果を共有。スマホは端末の共有メニュー、共有メニューのないPCはクリップボードにコピーする（PCは `S`）
- 「もどる」でトップへ（PCは `Esc`）

共有文の例：

```
居合 十二体斬り【十人斬り】／最速 231ms／救った猫天使 3匹
https://<ユーザー名>.github.io/retro-arcade/
```

**自己ベスト**：「最多撃破数」と「最速反応」を、**PCの部**と**スマホの部**（指で操作する端末）に分けて保存する。更新すると紙吹雪とファンファーレで祝う。

反応時間は「絵が画面に出たフレーム」から「タップ／キーを押した瞬間」までを測っている。

## ファイル構成

```
index.html, index.js   トップページ（店内）
games.js               筐体の一覧（1行＝1台）
shared/                全ゲーム共通の部品
  palette.js             16色パレット（色はすべてここから）
  base.css               画面の配置、スマホのジェスチャー無効化
  screen.js              256×240の画面と整数倍拡大、ゲームループ
  input.js               pointerdown／キーボード入力
  text.js                ドット文字（DotGothic16 / Press Start 2P）、漢数字
  audio.js               Web Audioの効果音合成
  ui.js                  ボタン、トップへ戻る
  store.js               localStorage（キーは retro-arcade:ゲーム名:項目）
games/iai/             居合
  index.html, game.js
  assets/oni.png, assets/neko.png
CLAUDE.md              開発ルール
```

手元で動かすときは、リポジトリのフォルダで簡単なサーバーを立てて開く（例：`python3 -m http.server` → `http://localhost:8000/`）。

## ゲームの追加方法

1. `games/` の下にゲーム名のフォルダを作る（例：`games/kingyo/`。名前は英小文字・数字・`-`）。
2. その中に `index.html` を置く。居合の `games/iai/index.html` を写して、最後の `game.js` を自分のスクリプトに差し替えるのが早い。共通部品は相対パス `../../shared/...` で読む。
3. ゲームのスクリプトでは共通部品を使う。

   ```js
   const canvas = document.getElementById('screen');
   const ctx = RA.setupScreen(canvas);          // 256×240、整数倍で中央に表示
   const back = RA.backButton();                // 左上の「もどる」ボタン（押したら RA.goTop()）
   RA.bindInput(canvas, {
     press(ev) { /* ev.x, ev.y は画面座標、ev.t は押した時刻 */ },
     key(ev) { /* ev.code === 'Space' など */ },
   });
   RA.loop((ts) => {
     ctx.fillStyle = RA.P.night;                 // 色は必ずパレットから
     ctx.fillRect(0, 0, RA.W, RA.H);
     RA.text(ctx, 'はじめる', 128, 112, { color: 'cream', align: 'center' });
     back.draw(ctx, ts);
   });
   RA.Audio.tone({ f: 880, dur: 0.1 });         // 効果音は合成で
   RA.Store.set(['kingyo', 'best'], 10);        // → retro-arcade:kingyo:best
   ```

4. `games.js` に1行足す。これで店内に筐体が1台増える。

   ```js
   { id: 'kingyo', title: '金魚', desc: '金魚をすくえ。', color: 'orange', thumb: 'assets/kingyo.png' },
   ```

   | 項目 | 内容 |
   | --- | --- |
   | `id` | フォルダ名（必須） |
   | `title` | 看板の名前（必須。看板に入りきらなければ流れる） |
   | `desc` | 一言紹介（全角15文字まで） |
   | `color` | 看板の色。`shared/palette.js` の色名 |
   | `thumb` | 筐体の画面に映す絵（ゲームのフォルダからの相対パス。配列にすると順番に切り替わる） |

守るべきルールは `CLAUDE.md` にまとめてある（相対パスのみ、16色パレットのみ、入力は pointerdown で即時判定、など）。

## 居合の画像の差し替え方法

鬼と猫天使の絵は次の2枚。**同じ名前のPNGで上書きするだけ**で、ゲームにもトップページの筐体の画面にも反映される。コードを触る必要はない。

| ファイル | 中身 |
| --- | --- |
| `games/iai/assets/oni.png` | 鬼 |
| `games/iai/assets/neko.png` | 猫天使 |

- 推奨は **32×32ドットの背景透過PNG**。ゲームでは96×96ドットの枠に、収まる最大の整数倍（32×32なら3倍）で、枠の下端中央にそろえて描く。大きさの違う絵でも枠に収まる
- 鬼と猫天使は同じ大きさ・同じ位置に出る。見分けるヒントは絵の違いだけなので、そこが勝負の肝になる
- 色は `shared/palette.js` の16色に合わせると、サイト全体の色調がそろう
- ブラウザに古い絵が残っているときは再読み込みする（GitHub Pages は数分ほどキャッシュすることがある）
